# dsh-geek-sidebar

DSH Web 的极客侧栏插件：把工作台的左侧边栏和文件区改造成一个"项目指挥部"。

## 它能做什么

- **项目与会话管理**：一键切换工作区（可自定义任意目录）、git 分支徽标一目了然；正在跑的会话有小圆点提示，别的工作区有几条会话在跑直接看工作区按钮上的数字徽标。每个项目的会话按时间列开，可归档。git worktree 也能直接查看和新建。
- **@ 文件提及**：输入框敲一个 `@`，当前项目文件立刻列出来随打随筛；或在文件管理器里点行上的 `@` 按钮，把文件路径带进对话上下文——不用再手动复制粘贴路径。
- **文件管理器与应用内预览**：侧栏下半区是完整文件树，支持上传、下载打包、搜索、两击确认删除；chat 里产出的文件链接点击不再跳浏览器，直接在应用内右侧面板打开预览（Markdown Source / Preview / Diff 三态、代码高亮、CSV 表格、图片缩放），"确定保存"才落盘。
- **知识库目录**：侧栏底部"笔记"页签是长效知识库目录的入口，多个目录随时切换、隐藏文件也照常显示，点开即排版预览。
- **便签与划选引用**：底栏一键打开全局便签抽屉，Typora 式编辑即预览、不绑会话；聊天记录里划选文本自动弹气泡，可一键"存入便签"或生成紧凑小胶囊"引用到对话"（长文本自动提取首尾词，发送时完整展开交付模型）。便签按 `.md` 路径提成 @ 提及，支持 AI 提炼标题、跨目录总览拖拽归类、一键转存至知识库或当前项目。
- **技能管理**：底栏"技能"打开技能中心，看来源/版本/说明、开关随点随切、搜索安装新技能、检查更新。

## 安装

```bash
dsh plugin --profile web add dsh-geek-sidebar
```
